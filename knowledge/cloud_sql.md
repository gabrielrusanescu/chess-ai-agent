# Cloud SQL

Cloud SQL is a managed relational database service.

## Main characteristics

- Supports relational tables and SQL queries.
- Appropriate for structured data with known relationships.
- Supports transactional application workloads.
- Reduces the operational effort required to install, patch, back up, and maintain a database server.

## Typical use cases

- Web and mobile application back ends
- Business applications
- User, order, inventory, and booking data
- Systems requiring joins, constraints, and transactions

## When not to choose it

Cloud SQL is not object storage and is not designed as a replacement for a large-scale wide-column database. The access pattern and data model should drive the service choice.
