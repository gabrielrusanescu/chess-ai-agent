# Day 2 — Data Services

## Main topics

- Choosing a storage or database service based on the data model and access pattern
- Cloud Storage for objects and files
- Cloud SQL for relational data
- Bigtable for large-scale, low-latency key-value and wide-column workloads

## Practical activities

Students created and used a Cloud Storage bucket, worked with a managed Cloud SQL database, and explored Bigtable schema design and querying.

## Service-selection summary

- Use Cloud Storage for files, media, backups, archives, and other objects.
- Use Cloud SQL when the application needs relational tables, SQL queries, transactions, and joins.
- Use Bigtable for very large datasets that require predictable low-latency access through carefully designed row keys.
