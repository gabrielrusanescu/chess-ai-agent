# Chess Notation, Time Controls, and Tournament Rules

Standard notation and formal regulations ensure clarity in recording games and maintaining fair play in competitive chess.

---

## Algebraic Chess Notation

Algebraic notation is the international standard method for recording and describing chess moves.

### Square Naming
- Each square is identified by a file letter (**a–h**) followed by a rank number (**1–8**).
- Examples: **e4**, **d5**, **c1**, **h7**.

### Piece Abbreviations
| Piece | English Abbreviation |
| :--- | :---: |
| **King** | **K** |
| **Queen** | **Q** |
| **Rook** | **R** |
| **Bishop** | **B** |
| **Knight** | **N** |
| **Pawn** | *(No letter; specified by target square only)* |

### Movement & Symbol Conventions
- **Piece Move**: Piece letter + destination square (e.g., `Nf3`, `Bc4`, `Qd4`).
- **Pawn Move**: Target square only (e.g., `e4`, `d4`).
- **Capture**: Interpose `x` between piece/file and destination square:
  - Piece capture: `Bxf7` (Bishop captures on f7), `Nxd4` (Knight captures on d4).
  - Pawn capture: Departure file + `x` + destination square (e.g., `exd5`, `cxd4`).
- **Castling**:
  - Kingside (Short): `O-O`
  - Queenside (Long): `O-O-O`
- **Pawn Promotion**: Appending `=` and promoted piece symbol (e.g., `e8=Q`, `b1=N`).
- **Check**: Append `+` at the end of the move (e.g., `Qh5+`).
- **Checkmate**: Append `#` at the end of the move (e.g., `Qxf7#`).
- **Disambiguation**: If two identical pieces can move to the same square, specify the file of origin (e.g., `Rad1`), or the rank of origin (e.g., `N5f3`) if on the same file.

## FIDE Time Controls

Chess games are played using dual digital clocks with defined time controls:

1. **Classical (Standard)**: Long time control used in major tournaments. Typically 90 minutes for the first 40 moves, followed by 30 minutes for the rest of the game, with a 30-second increment per move starting from move 1.
2. **Rapid**: Each player gets between 10 and 60 minutes for the entire game (frequently 15 minutes + 10-second increment).
3. **Blitz**: Fast-paced chess where each player has 3 to 5 minutes total (e.g., 3 minutes + 2-second increment).
4. **Bullet**: Ultra-fast chess with less than 3 minutes per player (commonly 1 minute total with no increment or 1 minute + 1-second increment).

### Increments vs. Delays
- **Fischer Increment**: Added time (e.g., 3 seconds) credited to a player's clock after making each move.
- **Delay**: A set buffer period (e.g., 5 seconds) per move before a player's remaining main time begins ticking down.

## Key Tournament Rules

- **Touch-Move Rule**: If a player touches a piece on their turn, they must move that piece if it has a legal move. If they touch an opponent's piece, they must capture it if legally possible.
- **"J'adoube" / "I Adjust"**: A player must declare their intent to adjust a piece on its square prior to touching it.
- **Scoresheets**: Players must record moves in algebraic notation during Classical games until fewer than 5 minutes remain on their clock without increment.
- **Clock Management**: Press the clock button with the same hand used to move the piece.
