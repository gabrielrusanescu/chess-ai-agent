# Day 1 — Google Cloud Foundations and Compute

## Main topics

- Cloud computing and on-demand access to computing resources
- The difference between infrastructure, platforms, and software services
- Google Cloud projects and the resources they contain
- Regions and zones
- Google Cloud Console and Cloud Shell
- Compute Engine virtual machines
- Virtual Private Cloud networks
- Firewall rules and external access

## Practical activities

The class explored the Google Cloud interface and created a virtual machine. Students inspected the machine configuration, connected to it, and observed how networking and firewall rules affect access.

## Core idea

A virtual machine provides an operating system and allocated compute resources. The user manages the software installed inside the machine, while Google manages the underlying physical infrastructure.
